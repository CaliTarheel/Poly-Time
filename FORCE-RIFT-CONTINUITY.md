# Fixed virtual-interface continuity across control-label churn

A plate's dominant-owned control set can gain a remote control while its held
piece and native cut remain unchanged. The old bounded-policy support digest
includes the entire owned set and its complement, so this event retires the
candidate even when it represents the same fixed virtual opening coordinate.

This change adds a narrow supplemental proof. It preserves the original digest
byte-for-byte and leaves the old exact-match branch intact. A second branch can
match only two consecutive, future-recorded proofs for the same host UID,
global selected piece, ordered native cut geometry, complete represented material
patch-side assignment and axis at the existing 1e-10 tolerance. Only remote
complementary control membership is omitted. It does not use overlap, infer a
past proof, search retired paths, or exchange/reverse the two sides.

## Why the omitted labels do not define this coordinate

The existing full-ledger daughter basis is

    omega_i = U + (I_piece(i) - alpha) * q * axis

where U is a freely solved common rotation, q is the differential coordinate,
and alpha is the current support-area fraction of the selected piece. The
supplemental branch requires a supported opening mode with common motion
relaxed and a complete current force ledger. If a remote control becomes part
of the complementary side, its indicator remains zero. A changed alpha can be
absorbed by U_new = U_old + (alpha_new - alpha_old) * q * axis. This preserves
the field on common controls and extends the same rest-side field to the new
control. It does not claim the new force equilibrium is unchanged.

The signed velocity across the fixed interface is independent of U and alpha.
The proof binds sorted edge IDs, ordered global endpoints and their coordinates,
edge midpoints, edge lengths and the oriented side signs. These are exactly the
inputs used by breakup_mode._cut for the normal/shear velocity and the
length-weighted opening coordinate. Missing, nonfinite, noncrossing or degenerate
geometry does not produce a proof; the same 1e-14 geometric validity thresholds
as _cut are retained. Current strengths may evolve because they are repriced,
not copied from an older work receipt.

The original whole-patch/craton side calculation supplies the complete unique
host patch-to-side pairs. A patch assigned to both sides is ineligible. New,
lost, reassigned or differently sided represented patches change the proof.
Missing represented material fields retain their existing error; absent complete
material representation cannot qualify the supplemental branch.

## History and compatibility

Rows optionally record fixed_interface_continuity with version 1, scope
fixed_native_virtual_interface, a SHA-256 identity, owner UID and bounded counts.
They also record support_match_kind as exact, fixed_interface or new_observation.
Frame validation checks these optional fields; old frames without them remain
valid. Empty proof dictionaries mean unavailable and cannot claim fixed_interface.
A supplemental match still requires the original consecutive policy epoch.

Existing rows without a new proof cannot use the new branch. They can continue
under the original exact identity, then record proof for later intervals; if the
old identity changes first, the existing conservative reset applies. A first or
replacement observation earns no preceding interval. There is no reconstruction
of earlier opening or reactivation of retired credit.

Every newly accepted increment still runs the unchanged current-force solve,
current mixed cut capacities and _paid_opening work budget. A changed geometry,
material side, UID or axis, a gap, or missing proof preserves intact re-selection
and retirement. Healing does not refund paid work. Retired paid work remains in
the cumulative ledger. Insufficient work rejects the update atomically.

## Scientific scope and validation

This is a correction to the existing rigid-until-breakup, fixed native virtual
interface model. It is consistent with Scotese's load-driven rifting and
inherited-weakness guidance: ownership labels alone are not a new geological
tear. The gauge calculation is a computational statement about this model,
not a new physical law or a claim that continental extension is realized.

It does not transport a tear with moving material, add a strain/damage point
network, change native resolution/tolerances, or implement gradual material
necking. A material-attached carrier/ancestry model is a separate, broader
policy. This narrow proof cannot establish general material continuity across
changing cut geometry, and it does not retroactively qualify any saved run.

The tiny suite exercises the actual extracted _basis and _cut functions,
current cohesive-work pricing, and stubbed search/update bookkeeping. It checks
remote-label continuity; signed relative rates and weights; geometry, side,
material, UID, axis and missing-proof rejection; optional frame schemas; current
capacity repricing; gaps, duplicate epochs, healing, atomic work failure and
nonrevival of retired paths. It constructs no simulation and advances no world.
There is no performance claim or full-world outcome claim. Source publication
alone does not migrate or restart a live simulation; adoption remains a separate
reviewed transition from a durable accepted checkpoint. The alert-only interval
clock and all process/controller code are outside this change.
